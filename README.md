# grill

An interview-prep app: browse curated Q&A topics and references, then build
a personal layer on top of them — ask follow-up questions on any selection,
write notes, and bookmark what matters, all stored locally and exportable as
JSON.

Built with Bun, Vite, React, TypeScript, Tailwind v4, and shadcn.

## Scripts

- `bun run dev` — start the dev server
- `bun run build` — type-check and build for production
- `bun test` — run the test suite
- `bun run lint` — lint with oxlint
